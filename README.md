## 🔭 What I'm Focused On

- 🌐 **Cisco Networking (CCNA):**
  - Routing & Switching protocols (OSPF, STP, EtherChannel).
  - Subnetting (IPv4/IPv6), VLANs, Inter-VLAN Routing, and Network Security (ACLs, Port Security).
  - Building enterprise network topologies using **Cisco Packet Tracer** and **EVE-NG / GNS3**.

- 📡 **MikroTik RouterOS (MTCNA Level):**
  - RouterOS v7 installation, WinBox interface management, and CLI configuration.
  - Bandwidth management (Simple Queues, Queue Trees), NAT rules, and Firewall filtering.
  - Hotspot management, DHCP server setup, and ISP failover configurations.

- 🐧 **Linux System Administration (RHCSA):**
  - Red Hat Enterprise Linux (RHEL) system deployment and management.
  - User/Group administration, file permissions, and process control using `systemd`.
  - Storage management using **LVM**, VDO, partition table setup, and file system maintenance.
  - Basic automation via **Bash scripting** and system security with **SELinux** & `firewalld`.
